description: Найти готовое решение вместо написания кода — воронка wheel (S0–S6)
---
Запусти скилл `wheel` по задаче: $ARGUMENTS

Если аргументов нет — возьми задачу из текущего контекста сессии; если и её нет, спроси одной строкой, что нужно сделать.

Пройди конвейер полностью, шаги не пропускай: классификация (S0) → инвентарь возможностей (S1) → грилинг вопросами из различий кандидатов (S2) → поиск на рынке (S3) → зазоры × зрелость → режим внедрения (S4) → forward-look (S5) → вердикт (S6).

Вердикта «пишем с нуля» не выдавай: если кандидатов не нашлось, продолжай грилинг, пока ответ пользователя не даст новую зацепку для поиска.
